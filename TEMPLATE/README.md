# TEMPLATE — Reusable PoC Documents

> Standard templates for requirements, user journeys, solution design, and architecture documentation.

## Files

| File | Purpose |
|------|---------|
| `01-requirements.md` | Requirements gathering template |
| `02-user-journeys.md` | User journey mapping template |
| `03-solution-design.md` | Solution design document template |

## Usage

Copy these templates when starting a new engagement or PoC phase. Fill in the bracketed placeholders with project-specific content.
